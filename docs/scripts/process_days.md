# Script 09 — process_days.py

**Version:** 2.1  
**Pipeline stage:** 8 — Water-Supply Days

## Purpose
Calculates observed days, days with scheduled water, days without water, and duplicate-day conflicts for each calendar grouping, with quality-control logging.

## Input and output
| Component | Description |
|---|---|
| Input | CSV generated by `match_wc_uid.py` |
| Input directory | `calproc_wcuid/` |
| Required columns | `year`, `month`, `day`, `has_water`, `group_uid`, `wc_uid` |
| Output | CSV with `days_observed`, `days_with_water`, `days_without_water`, `conflict_days`, and pipeline metadata |
| Output directory | `calproc_days/` |
| QC logs | `logs/days_excluded.csv`, `logs/days_errors.csv` |
| Next stage | `process_hours.py` |

## Processing
1. Reads the input CSV and validates its required columns.
2. Logs and excludes invalid QC rows, nonnumeric days, and days outside 1–31.
3. Converts `has_water` to a binary indicator.
4. Collapses duplicate day keys using the maximum `has_water` value, recording conflicting values.
5. Aggregates unique observed days and water-supply days by grouping keys, and derives days without water.
6. Logs conflicts, excessive day counts, and groups with fewer than 20 observed days.
7. Writes a UTF-8-SIG CSV, retaining all summarized groups.

## Called scripts and dependencies
- **Other project scripts called:** None.

## Review flags
- Despite the comment, `schedule` is included in the daily and monthly grouping keys; distinct schedules can yield separate records.
- The 20-day incomplete-coverage warning threshold is hardcoded and may flag valid half-month calendars.
- QC logs are appended to on reruns, potentially accumulating duplicates.
- `no_water_dir` and `errors_dir` are documented as configuration keys but not used to produce separate outputs in this script.
- The script checks day values against 1–31, not against the specific month's length or period.
